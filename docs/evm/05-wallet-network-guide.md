# دليل إضافة شبكة SmartNode Testnet إلى المحافظ

**الحالة: مسودة توثيقية. لم يُختبر ربط أي محفظة فعلياً، ولا يُعلَن نجاح الربط.**

هذا الدليل يخص الـTestnet الجديدة فقط. لا يغطي Mainnet، ولا يُستخدم فيه أي مال حقيقي.

## معلمات الشبكة

| البند | القيمة | الحالة |
|---|---|---|
| اسم الشبكة | SmartNode Testnet | مقترح |
| Chain ID | `20261122` (0x1352902) | معتمد من المالك، بانتظار الفحص النهائي على chainid.network |
| العملة الأصلية | SNN | مقترح |
| منازل عشرية | 18 (1 SNN = 10^18 وحدة أساسية) | معتمد لطبقة EVM |
| RPC | `<عنوان RPC العام للـTestnet>` | بانتظار النشر |
| مستكشف الكتل | غير متاح | — |

## تنبيهات قبل الإضافة

- Chain ID لم يُفحص بعد على chainid.network بفحص دقيق. لا تضف الشبكة إلى محفظة عامة قبل ذلك الفحص.
- الحد الأدنى للتحويل العادي 0.000001 SNN (10^12 وحدة أساسية).
- سعر الغاز ثابت للـTestnet فقط، وحدّه الأقصى للمعاملة 3,000,000 وحدة غاز.
- لا تُستخدم مفاتيح المحفظة الحقيقية في هذه الشبكة.

## الإضافة اليدوية (`wallet_addEthereumChain`)

يمكن للمحافظ المتوافقة مع EIP-3085 إضافة الشبكة بهذه المعلمات بعد نشر عنوان RPC:

```json
{
  "chainId": "0x1352902",
  "chainName": "SmartNode Testnet",
  "nativeCurrency": { "name": "SmartNode", "symbol": "SNN", "decimals": 18 },
  "rpcUrls": ["<عنوان RPC العام للـTestnet>"]
}
```

قيمة `chainId` في الحقل هي 20261122 بالسداسي عشري (0x1352902).

## ما يعمل وما لا يعمل

- يعمل حسب المرحلة D الموثقة في `docs/evm/README.md`: قراءة الرصيد والـnonce، وإرسال التحويلات البسيطة الموقّعة، وتقدير الغاز للتحويلات البسيطة، والإيصالات.
- لا يعمل بعد: استدعاء العقود، وإنشاؤها، وسجلات الأحداث، ومعاملات EIP-2718 المكتوبة.

## قائمة التحقق قبل الإعلان عن دعم محفظة

1. فحص Chain ID النهائي على chainid.network وethereum-lists/chains.
2. نشر RPC عام مستقر، واختبار كل طريقة مستخدمة من المحفظة.
3. اختبار الإضافة والتحويل الفعلي في كل محفظة (MetaMask، Trust Wallet، Binance Web3 Wallet) على متصفح حقيقي.
4. تسجيل النتيجة لكل محفظة بتاريخ ونسخة الشبكة، وعدم الإعلان قبل ذلك.
